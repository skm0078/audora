# Add a book: every way in, from the Add book button (2026-10-29, ADR 2026-10-29-add-a-book)
- Add book opens a sheet: Choose a file, Point and read (take a photo), pictures from the gallery, copied text, a web
  page, free book catalogues and watched folders, each with one line on what it reads. The empty library's Add book
  opens it too.
- Those six leave the library's ⋮ menu. Search finds them under "Library › Add book".
- "What's new" entry: `app/src/main/assets/whatsnew/2026-10-29-add-a-book.txt`. `:pdf` unchanged. No new dependency.
- **Cost:** six vector icons (under 2 KB); the sheet is composed only while open. Nothing at start-up or while
  scrolling.
- **Could affect:** the Add book button, the empty library's button, the library ⋮ menu and search's library rows.
- **Verified in CI:** `AddBookSourceTest`, `AddBookSheetTest`, `WebBooksScreenTest`, release journey step 41 (now
  through the sheet).

**Real-device checks (the test phone):** tap Add book: the sheet lists seven ways in, each with a line. Choose a file
opens the picker with the sheet gone. Point and read opens the camera; Free book catalogues opens its list; Back
returns to the library, not the sheet. ⋮ no longer lists them. Search "web": Read a web page shows under "Library ›
Add book". TalkBack reads each row's name, line and info button.
