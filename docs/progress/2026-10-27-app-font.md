# The app's own font in English, Hindi and Bengali (2026-10-27)
- Every screen's text is now set in **Anek**, one open-source design drawn for English, Hindi and Bengali, so all
  three languages look like the same app on every phone. Book text keeps the reader's own fonts.
- Nine files in `app/src/main/res/font/` (`anek_{latin,devanagari,bangla}_{regular,medium,semibold}.ttf`), each
  trimmed to its own script: about **0.74 MB** added to the APK. Joined per weight by `ui/theme/AppFont.kt` with
  Android's custom font fallback; other scripts and emoji still use the phone's fonts. ADR
  `docs/adr/2026-10-27-app-font.md`.
- Headings use weight 600, the heaviest file bundled, so no bold is faked.
- Voices & licences credits Anek; its OFL text is in `assets/licences/anek-OFL.txt`.
- "What's new" entry: `app/src/main/assets/whatsnew/2026-10-27-app-font.txt`. No `:pdf` change. No new dependency.
- **Could affect:** every screen's text width and height (slightly narrower than Roboto), Voices & licences.
- **Verified in CI:** `AppFontTest` (every style in the app font, three real weights, script files in fallback
  order, one load per weight), `AppFontDeviceTest` (English, Hindi and Bengali each draw differently from the phone's
  sans, so each script's file loaded; screenshot `app-font.png`), `ReleaseJourneyTest` step 18 (each weight loads
  from the installed APK and draws all three scripts), the UI tour at font scale 2.

**Real-device checks (the test phone):** open the library in English, then switch the app language to Hindi and to
Bengali: titles and buttons look like one design in all three, nothing is cut or overlapping at the largest font
size. Settings → Voices & licences ends with Anek in the Fonts section.

**Fix (2026-10-28):** the trimmed files kept the variable font's default names, so all three weights of each script
were called "Anek <script> Medium" (PostScript `Anek<script>-Medium`), and on the emulator Bengali at weight 500 was
not drawn from its own file. Each file now carries its own family, style and PostScript name. Release journey step 18
now checks that each weight draws each script exactly like that weight's own file, and that a script's three weights
measure differently, instead of only "unlike the phone's sans" (two fonts can measure alike by chance).
