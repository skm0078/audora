# ADR 2026-10-28-made-tab: Made as covers or a list, and its player built like the book player

**Status:** Accepted (2026-10-28). Follows the Made mockups on the design canvas (row "Made: same player, same
settings, grid or list"), which the maintainer approved, asking for polish and for colours, fonts and everything else
to stay consistent with the rest of the app.

## Context

Made listed every saved file as a text card with four text buttons (Play, Open, Share, Delete) under a Jobs card. Its
player was a page of its own: a list of files under a row of buttons, a "Speed" button that stepped through six
speeds and no sleep timer. The maintainer: the player can be the book player, or if not it must be designed as well,
with controls and details and the screen used well; the list's buttons can be icons; the library's grid should apply
here too; and the settings should be reached from the same place.

## Decision

- **Grid or list, the library's own choice.** Made shows the books' covers in a grid (two across a phone) or the
  library's rows, following `LibraryLayout` from the library's Preferences DataStore, so one choice serves both
  places. A grid/list toggle in Made's top bar sets the same value. Automatic stays a list at large text sizes.
- **Icon buttons.** Each set has a filled Play (Open, with the kind's icon, for a copy or talking book), Share, and ⋮
  with Delete. Each is named for TalkBack with the book and kind ("Play Gitanjali, Audiobook"). A tap on the cover
  plays too. A set whose files are all gone keeps "Remove from the list" as words.
- **Kind on the cover, filter by kind.** The cover carries a small dark badge with the kind; chips above the list
  (All, then each kind there is, with counts) filter it once there is more than one kind.
- **Jobs in the top bar.** "Jobs", or "2 making" while jobs run, as a chip. TalkBack hears "Jobs and downloads".
- **The player is laid out like the book player.** Back, "Made · Audiobook" over the book's title, Chapters (the book
  player's chapter list, one row per file) and Share; the book's cover large with the chapter's name and when it was
  saved; a seek bar with position, chapter n of N and time left; and the book player's raised controls panel:
  previous chapter, back 15 s, a large Play, forward 30 s, next chapter, then Speed and the sleep timer under them.
- **The same settings from the same place.** Speed opens a sheet with the book player's own name ("Voice and speed")
  and its own speed control (`SpeedBlock`, slider and presets). Since a saved file keeps the voice it was made with,
  the sheet says so and points to the book's menu, Save as, instead of offering voices that would do nothing. The
  sleep timer is the book player's button and menu (`SleepTimerMenuButton`, now shared), with minutes and, for a set
  of more than one file, the chapter choices; End of page has no meaning here and is left out.
- **The timer runs in the saved-audio service.** `MadeAudioService` takes a custom `SLEEP` command from this app's
  own screens only, pauses after the minutes (a main-thread `Handler`), or at the end of the chapter or the Nth from
  here (ExoPlayer's `pauseAtEndOfMediaItems` on the last one), and publishes the timer in its session extras, which
  the screen reads back. It keeps counting with the screen off. Loading another set turns it off.

## Alternatives

- **Play saved files in the book player itself.** The book player is built on the reading service's sentences,
  pages and voices; a saved MP3 has none of them. Feeding files through it would mean a second mode in every part of
  that player. Sharing its pieces (panel, speed control, timer, chapter list) gives the same look without that.
- **A separate grid/list choice for Made.** Two settings for one idea; the maintainer asked for settings from the
  same place.
- **Timer in the screen.** It would stop when the screen goes, which is when a sleep timer matters.

## Consequences

- `SleepTimerMenuButton` and `SpeedBlock` are shared by both players; a change to either shows in both.
- Picking grid or list in Made changes the library too, and back.
- **Cost:** no new dependency, no new work at rest. The grid reuses the library's cover cache (covers already made
  for the library are read from memory or disk). The timer is one Handler post or one ExoPlayer flag. APK a few KB.
