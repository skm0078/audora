# ADR 2026-10-27-app-font: Anek as the app's own type in English, Hindi and Bengali

**Status:** Accepted (2026-10-27). First step of the design pass the maintainer asked for before v0.1.0 (mockups on
the design canvas, rules in "ListenLock design and growth system"). Replaces the "phone's own fonts" note in
`AudoraTheme`.

## Context

The app's text used the phone's sans: Roboto for English and Noto for Hindi and Bengali. They are good faces but
not one design, and they differ by phone maker, so the same screen looks different across phones and a Hindi title
next to an English one reads like two apps. The maintainer asked for consistent, open-source typography and for
every change to state its cost on the phone.

## Decision

- **Anek** (Ek Type, SIL Open Font License 1.1, version 1.003 from google/fonts) is the UI type. One family drawn
  for Latin, Devanagari and Bengali, with matching weights and proportions.
- Shipped as **static files trimmed to their own script**: Latin (Basic Latin to Latin Extended-B, punctuation,
  currency, arrows), Devanagari (with its extended blocks, dandas, ₹ and the dotted circle) and Bengali, at 400, 500
  and 600, width 100. OpenType layout features are kept so conjuncts and matras shape correctly; hinting is dropped.
  The variable files would be 3.9 MB; the nine trimmed files are 1.66 MB on disk and about **0.74 MB compressed in
  the APK**.
- Joined per weight with `Typeface.CustomFallbackBuilder` (API 29+, minSdk 31): Latin, then Devanagari, then
  Bengali, then the phone's sans for any other script, emoji and symbols. Compose's font list picks files by weight
  only, so a small `AndroidFont` subclass (`AppFont.AnekFont`) hands Compose that joined typeface.
- Every Material text style uses it. Headings that asked for bold now ask for 600, the heaviest file, so nothing is
  drawn as a synthesised bold; a stray `FontWeight.Bold` resolves to 600 as well.
- Book text is untouched: the reader keeps its own fonts (Book, Clean, Easy letters, Dyslexia-friendly).

## Alternatives

- **Downloadable fonts (Google Play services):** 0 KB, but needs Play services and a network fetch the app does not
  otherwise make; phones without it would see the old fonts. Rejected for an offline-first, no-network app.
- **Latin only, Noto for Indic:** about 0.1 MB, but brings back the mixed look in Hindi and Bengali.
- **Variable files:** one file per script, any weight, but 3.9 MB.

## Consequences

- APK grows by about 0.74 MB. No new dependency, no network, no permission.
- A font file that fails to load is logged (`AppFont`) and Compose falls back to the phone's sans for that weight.
- Text metrics change slightly (Anek is a little narrower than Roboto), which gives long Hindi and Bengali labels a
  bit more room.
