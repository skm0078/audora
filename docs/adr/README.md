# Architecture Decision Records

The decision log lives in [BUILD-SPEC.md §11](../BUILD-SPEC.md#11-decision-log-adrs) (ADR-001 to ADR-009).
A decision that changes after the spec lock gets its own file here, named `NNN-short-title.md`, with:
context, decision, alternatives considered, consequences. Then update the §11 table and bump the spec version.
