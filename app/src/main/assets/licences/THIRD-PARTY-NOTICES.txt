ListenLock: open-source notices
================================

ListenLock is free software under the GNU General Public License, version 3 (listenlock-GPL-3.0.txt). Its complete
source code, including the build scripts, is at https://github.com/skm0078/audora, with a Git tag for every
release.

ListenLock is built with the software below. Each entry names the work, its copyright holders, its licence and the
file in this folder that holds the licence's full text. Where a licence asks for a sentence in the documentation,
the sentence is quoted here.

Voices, speech and dictionary models are credited on the "Voices & licences" screen, each with its own licence; the
licence files a downloaded model carries are shown there under "Files". Fonts are credited on the same screen; their
licences are the *-OFL.txt files in this folder.
